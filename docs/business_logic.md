# Business Logic

## Общая идея
Вдохновлён Palmetto State Armory. Это backend интернет-магазина с категориями, брендами, товарами, заказами и корзиной. Реализована регистрация, авторизация, API и базовая административная панель.

---

## Сущности

### Категории
- Иерархическая структура: корневые категории > подкатегории > под-подкатегории.
- Отображаются в выпадающем меню при наведении.
- Имеют изображения и слаги.

### Бренды
- Имеют логотип, описание и slug.
- Отображаются в верхней части при наведении на "Brands" (с логотипами) и ниже — просто список.
- Все кликабельны и ведут на страницу с продуктами по бренду.

### Продукты
- Привязаны к категориям и брендам.
- Имеют изображения, цену, описание, количество.
- Можно отфильтровать по категории или бренду.

### Корзина
- У каждого пользователя своя корзина.
- Добавление и удаление товаров.
- Подсчёт общей суммы.

### Заказы
- Создаются из корзины.
- Содержат связанные товары, сумму, дату и статус.
- Для создания требуется аутентификация.

## UI и поведение меню
- Меню в верхней серой полоске.
- При наведении на категорию — появляется окно с подкатегориями.
- Между серым меню и выпадающим окном — красная линия.
- При наведении на **Shop All** — показываются все категории.
- При клике на категорию — появляется список её подкатегорий.
- **Daily Deals** — выделена красным, без hover-фона.
- При наведении на **Brands** — сверху логотипы брендов, ниже — список брендов текстом.

---

## Асинхронные задачи (Celery)
- Отправка писем при регистрации и заказах.
- Очистка неактивных заказов.
- Возможность расширения логики задач без перезапуска сервера.

## CI/CD
- Используется GitHub Actions для автоматизации тестов и деплоя.
- Проект разворачивается через Docker и Nginx.
